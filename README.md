# AgriLoss & Value Intelligence Rwanda 🇷🇼

**Data-Driven Agricultural Productivity, Post-Harvest Loss Reduction, and Value Addition**

## 1. Overview

AgriLoss & Value Intelligence Rwanda is a data-driven project developed for the **NISR 2026 Big Data Hackathon — Track 1: Agricultural Productivity**.

The project aims to analyze Rwanda's agricultural data to identify productivity challenges, investigate potential post-harvest losses, and support evidence-based decisions for improved crop storage, processing, and value addition.

By applying data analytics, visualization, and machine learning, the project seeks to transform agricultural data into actionable insights for farmers, policymakers, researchers, and agricultural stakeholders.

## 2. Problem Statement

Agricultural productivity depends not only on crop production but also on effective harvesting, collection, storage, processing, and market access.

Limited data-driven identification of agricultural challenges can make it difficult to prioritize interventions and improve the value obtained from agricultural production.

This project explores how Rwanda's agricultural survey data can help identify patterns associated with productivity challenges and guide targeted interventions.

## 3. Project Objectives

- Analyze Rwanda's agricultural survey datasets.
- Identify patterns in crop production and agricultural practices.
- Explore factors potentially associated with agricultural productivity.
- Investigate indicators relevant to post-harvest loss and storage challenges.
- Apply machine learning where suitable data and target variables are available.
- Develop visualizations and evidence-based recommendations.
- Support improved agricultural processing and value addition in Rwanda.
